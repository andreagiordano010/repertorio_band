# Repertorio Band

Archivio dei brani della band: tablature Guitar Pro (anche scaricate da Songsterr), note personali e punti chiave da riascoltare in loop e rallentati, con il suono della tablatura o insieme al video originale di YouTube.

I dati restano nel browser di chi usa l'app; dal menu laterale si può esportare e importare un backup.
